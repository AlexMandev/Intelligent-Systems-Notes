## Агент и среда
**Агент** - всичко, което **възприема** средата си чрез **сензори** (sensors) и **действа** върху нея чрез **изпълнителни механизми** (actuators). Агенти са хора, роботи, софтуерни агенти (softbots), термостати и т.н.

```
Среда --(percepts)--> [Сензори] -> АГЕНТ -> [Actuators] --(actions)--> Среда
```
- **Percept** (възприятие) - какво агентът "вижда" в даден момент
- **Percept sequence** - цялата история от възприятия до момента
- **Функция на агента** (agent function) - $f: P^* \to A$, изобразява историята от възприятия в действие
- **Програма на агента** (agent program) - конкретната имплементация на $f$, която работи върху физическата архитектура

###### Пример - прахосмукачка (vacuum world)
Две клетки A и B. Възприятие: `[локация, мръсно/чисто]`, напр. `[A, Dirty]`. Действия: `Left, Right, Suck, NoOp`.
```
if status = Dirty then return Suck
else if location = A then return Right
else if location = B then return Left
```

## Рационалност
**Мярка за представяне** (performance measure) - оценява последователността от състояния на средата (напр. +1 точка за всяка чиста клетка на всяка стъпка, -1 за всяко движение).

> [!important] Рационален агент
> Избира действието, което **максимизира очакваната стойност** на мярката за представяне, при дадената история от възприятия до момента.

- Рационален $\neq$ всезнаещ (omniscient) - възприятията може да не дават цялата информация
- Рационален $\neq$ ясновидец (clairvoyant) - действията може да не доведат до очаквания резултат
- Следователно рационален $\neq$ успешен
- Рационалност $\implies$ изследване (exploration), учене, автономност

## PEAS
За да проектираме рационален агент, трябва да опишем **средата на задачата** (task environment):
- **P**erformance measure - мярка за представяне
- **E**nvironment - среда
- **A**ctuators - изпълнителни механизми
- **S**ensors - сензори

| | Автоматично такси | Агент за пазаруване в интернет |
| --- | --- | --- |
| **P** | безопасност, стигане до целта, печалба, законност, комфорт | цена, качество, подходящост, ефективност |
| **E** | улици, трафик, пешеходци, време | сайтове, търговци, доставчици |
| **A** | волан, газ, спирачка, клаксон, дисплей | показване на потребителя, следване на URL, попълване на форми |
| **S** | камери, акселерометри, GPS, сензори на двигателя | HTML страници (текст, графики, скриптове) |

## Типове среди
| Свойство | Значение |
| --- | --- |
| **Наблюдаема** (observable) vs частично наблюдаема | сензорите дават ли **пълното** състояние на средата |
| **Детерминистична** vs стохастична | следващото състояние напълно ли се определя от текущото + действието |
| **Епизодична** vs последователна (sequential) | действията независими ли са едно от друго (напр. класифициране на снимки) или влияят на бъдещето |
| **Статична** vs динамична | променя ли се средата, докато агентът мисли (**semi** - средата не се мени, но оценката с времето да) |
| **Дискретна** vs непрекъсната | краен брой състояния/действия ли има |
| **Един агент** vs много агенти | има ли други агенти (противници/съюзници) |

|                | Peg Solitaire | Backgammon (табла) | Пазаруване в интернет | Такси |
| -------------- | ------------- | ------------------ | ------------------------ | ----- |
| Наблюдаема     | Да            | Да                 | Не                       | Не    |
| Детерминистична | Да           | Не (зарове)        | Частично                 | Не    |
| Епизодична     | Не            | Не                 | Не                       | Не    |
| Статична       | Да            | Semi               | Semi                     | Не    |
| Дискретна      | Да            | Да                 | Да                       | Не    |
| Един агент     | Да            | Не                 | Да (без търгове)         | Не    |

> [!warning] Реалният свят е частично наблюдаем, стохастичен, последователен, динамичен, непрекъснат и с много агенти. **Типът среда определя дизайна на агента.**

## Типове агенти (важно - картинки!)
Четири основни типа, подредени по нарастваща общност. Всеки добавя нещо към предишния:

### 1. Прости рефлексни агенти (Simple reflex agents)
- Реагират **само на текущото възприятие** чрез правила **условие-действие** (condition-action rules, if-then)
- Нямат памет
- **Проблем:** не работят в частично наблюдаеми среди (напр. ако прахосмукачката няма сензор за локация, може да зацикли безкрайно). Случайността помага малко.
- **На картинката:** само `What the world is like now` + `Condition-action rules` → `What action I should do now`

![[lec-agents-simple-reflex.png]]

### 2. Рефлексни агенти с памет (Model-based reflex agents / reflex agents with state)
- Пазят **вътрешно състояние** (State) - памет за света
- Обновяват го чрез **модел на света**: `How the world evolves` (как се развива светът) и `What my actions do` (какво правят действията ми)
- Все още избират действие чрез condition-action rules
- **На картинката:** има `State`, `How the world evolves`, `What my actions do` + `Condition-action rules`

![[lec-agents-model-based.png]]

### 3. Целеви агенти (Goal-based agents)
- Имат **цел** (Goals) и мислят напред: `What it will be like if I do action A` (какво ще стане, ако направя действие А)
- Тук влизат **търсенето и планирането** (всичко от [[Sem 02]] и [[Sem 03]])
- **На картинката:** `Goals` + `What it will be like if I do action A`, **няма** condition-action rules

![[lec-agents-goal-based.png]]

### 4. Максимизиращи ползата (Utility-based agents)
- Целта е само "постигната/непостигната". **Функцията на полезност** (utility) казва **колко добро** е дадено състояние (по-бързо, по-евтино, по-безопасно)
- **На картинката:** `Utility` + `How happy I will be in such a state`

![[lec-agents-utility-based.png]]

> [!important] Как да познаем типа от картинката
> Гледаме **най-напредналата** кутийка:
> - само `Condition-action rules`, без `State` → **прост рефлексен**
> - `State` + `How the world evolves` + `Condition-action rules` → **рефлексен с памет**
> - `Goals` → **целеви**
> - `Utility` / `How happy I will be` → **максимизиращ ползата**

**Learning agents (учещи се агенти)** - всеки от четирите типа може да се превърне в учещ се агент (добавя critic, learning element, problem generator).

## Обобщение
- Агентите взаимодействат със средата чрез сензори и actuators
- Функцията на агента описва какво прави той при всякакви обстоятелства
- Перфектно рационален агент максимизира очакваното представяне
- PEAS описва средата на задачата
- Средите се класифицират по: наблюдаема? детерминистична? епизодична? статична? дискретна? един агент?
- 4 архитектури: рефлексен, рефлексен с памет, целеви, максимизиращ ползата
